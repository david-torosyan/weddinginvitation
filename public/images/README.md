# Wedding image guide

Replace files in these folders while keeping the filenames unchanged—no React code needs changing. All images use `object-fit: cover`; deliberate crops keep the composition stable.

| Section | File | Recommended size / crop |
| --- | --- | --- |
| Opening screen and hero | `hero/hero-main.jpg` | 2400×3200px, portrait, couple centred or slightly right |
| Day programme | `events/bride-house.jpg`, `church.jpg`, `reception.jpg` | 1800×1400px, landscape or gentle portrait |
| Gallery | `gallery/photo-01.jpg` to `photo-05.jpg` | at least 1600px on the long edge; mix portrait and landscape |

For every replacement, export WebP or JPEG at quality 75–85, strip metadata, and keep files below about 500KB where practical. The hero crop is centre/right on small screens and centre on larger screens. Event and gallery images use centre crops; choose images with the subjects away from the outer edges.
